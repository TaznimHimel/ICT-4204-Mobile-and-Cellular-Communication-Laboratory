A collection of simple Python simulations for selected Mobile and Cellular Communication laboratory experiments.

## Experiments

### 1. Calculation of Doppler Shift and Maximum Mobile Velocity
- Calculate Doppler frequency.
- Determine maximum mobile velocity.
- Analyze the effect of carrier frequency and direction of movement.

### 2. Calculation of Co-channel Reuse Distance and Reuse Ratio
- Calculate reuse distance and reuse ratio.
- Analyze the effect of cluster size on co-channel interference.

### 4. Study and Simulation of GSM Network Architecture
- Identify MS, BTS, BSC, MSC, HLR, VLR, AuC, and EIR.
- Demonstrate their functions and communication flow.

### 5. Simulation of Handover Between Two Cellular Cells
- Simulate mobile movement between adjacent cells.
- Measure received signal strength.
- Determine the handover point.

### 8. Analysis of Cell Coverage, Cell Radius, and Cell Splitting
- Simulate cell coverage.
- Vary cell radius and transmit power.
- Analyze the effect of cell splitting on coverage and capacity.

## Technologies Used

- Python 3
- NumPy
- Matplotlib

## Installation

Install the required Python libraries:

```bash
pip install numpy matplotlib
```

## How to Run

Clone the repository:

```bash
git clone <repository-url>
cd <repository-folder>
```

Run an experiment using:

```bash
python <experiment-file>.py
```

For example:

```bash
python handover.py
```

## Requirements

Create a `requirements.txt` file containing:

```text
numpy
matplotlib
```

## Output

Each experiment generates its corresponding numerical results and graphical visualization when executed.
